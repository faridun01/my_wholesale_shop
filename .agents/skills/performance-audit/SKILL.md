# Performance Audit

Optimize real bottlenecks.

Check:
- slow API endpoints
- slow DB queries
- N+1 queries
- pagination
- server-side filtering/search/sort
- PostgreSQL indexes
- Prisma query efficiency
- large API payloads
- unnecessary frontend requests
- React re-renders
- lazy loading
- code splitting
- bundle size
- caching
- connection pooling
- long transactions
- memory leaks
- concurrency

Preserve correctness and business logic.

Measure performance before and after when possible.
