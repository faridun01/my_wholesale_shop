# Security Audit

Check and fix:
- authentication
- JWT/session handling
- RBAC
- backend authorization
- IDOR
- privilege escalation
- password security
- input validation
- XSS
- injection
- CORS
- rate limiting
- brute force protection
- secrets
- sensitive data exposure
- dependency vulnerabilities
- Docker security

Never rely only on frontend permissions.

Fix discovered vulnerabilities instead of only reporting them.
