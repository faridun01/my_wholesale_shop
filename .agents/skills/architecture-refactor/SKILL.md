# Architecture Refactor

Audit the whole frontend/backend architecture.

Check:
- separation of concerns
- duplicated logic
- oversized services/components
- module boundaries
- API contracts
- shared types
- database/service responsibilities
- error handling
- transaction boundaries
- dead code

Refactor when necessary.

Do not change correct business logic.

After refactoring, verify that existing behavior remains unchanged.
